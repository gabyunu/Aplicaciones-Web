### **Workshop 2: Website con HTML + CSS**

Para este workshop se tomó como base la página creada anteriormente en **HTML** y se mejoró su presentación utilizando **CSS**. Primero, se organizó el proyecto siguiendo la estructura indicada, separando el archivo principal, las demás páginas, las imágenes y los estilos en diferentes carpetas.

Después, se creó un archivo **CSS independiente** y se vinculó correctamente con los archivos HTML. Con este archivo se modificaron los **colores**, el **menú de navegación**, las **secciones**, las **imágenes** y otros elementos visuales de la página.

También se agregaron **bordes redondeados**, **sombras**, degradados y algunos **efectos interactivos** al pasar el cursor sobre distintos elementos. Finalmente, se mantuvo el contenido desarrollado en el Workshop 1, pero con una apariencia más **ordenada, moderna, atractiva e interactiva**.
