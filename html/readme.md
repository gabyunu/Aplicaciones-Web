# Workshop 1: Website Only HTML

En este workshop se creó una página web utilizando únicamente **HTML5**, siguiendo una estructura organizada con `header`, `nav`, `main`, `section`, `article` y `footer`.

La página principal incluye **información personal, imágenes, intereses académicos y un menú de navegación** hacia las demás páginas del sitio.

También se organizaron los archivos HTML e imágenes dentro de sus respectivas carpetas para mantener una estructura clara del proyecto.

Para visualizar la página, se configuró **Apache como servidor web** y se utilizó `workshop1.webapp` apuntando a `localhost`. El proyecto fue abierto y probado desde **Visual Studio Code** en el navegador.

Finalmente, se verificó que la navegación y los recursos de la página funcionaran correctamente.
